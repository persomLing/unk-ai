# 浏览器图片指示与局部数据读取

> 当前界面说明（2026-11-05）：附件“＋”菜单已移除“当前页截图”和“框选区域”，只保留图片、文档上传及原有粘贴图片能力。以下截图/框选使用步骤与验收记录描述本次 0.17.9 交付时的界面；当前入口以 [README](../README.md) 为准。自动视觉与 Agent 截图辅助仍保留。

本次接通页面操作的图片输入，并为分页数字比较增加局部 DOM 读取、独立行数据累积和本地排序。普通问答内核、流式协议和浏览器动作权限体系保持原有执行路径。

## 使用方式

1. 选择支持视觉输入的模型，打开“页面操作”。
2. “＋”可以上传图片、截取当前页或框选截图区域；也可以粘贴图片。
3. 框选在侧栏内的冻结截图上拖动，添加后描述目标，例如：“按框出的缓存命中率字段，读取第 1、2、3 页所有商家，列出最高的 10 家并保留来源。”
4. 展开浏览器任务查看取数行数和观察、读取、模型、动作耗时。部分数据、缺失值和名称冲突不视为完整榜单。

截图用于定位参考；不新增任意坐标点击，也不自动将圈出的坐标变成 DOM 权限。Agent 按当前观察的区域名称、位置和元素引用核对，并调用 `read_region` 读取限定区域的数据。跨 frame 的矩形属于该 frame，不能直接映射到主页面截图。

## 已实现的边界

- 图片最多 3 张、合计 8 MiB；模型未标记视觉能力时明确拒绝，不能静默丢图。外部图片只作参考，不伪造页面来源。
- 截图保留 `tabId`、完整 URL、可获取的 `documentId`、捕获时间、视口/滚动位置、原图尺寸和裁剪区域。上传、截图、解码、框选与裁剪归属固定；切会话、换目标、取消或过期后不能迟到附加。
- 图片存入原用户消息，提交模型固定后由同一 Agent 决策请求通过 ModelGateway 发出。既有 `start(goal,{target})` 不足以携带用户图片，故只扩展参数传递、附件保存和验证，没有添加第二套发送或主回复。
- `read_region` 参数为真实 `elementId` 和最多 80 字符的字段名 `query`，只读、不执行脚本；本地等待和后台共用既有读取超时/取消边界。读取前后复核任务许可、站点授权、快照、完整 URL、主文档和目标 frame 身份。取消等待不会撤销之前已执行的页面动作。
- 区域覆盖表格、列表与重复卡片。行身份优先真实名称表头/标题等可见内容，排名列不能作为商家名；无法可靠取名时保留缺口。隐藏、编辑区和表单值不参与读取；截图本身不做自动脱敏。
- 单次最多 200 行，每行正文 800 字符，行文本/名称/表格 cells 合计 32000 字符；未识别行结构时最多 16000 字符区域正文。每行与整个结果分别标截断。
- 跨页数据最多 40 份区域记录、1200 行，行记录序列化预算 180000 字符；正文摘录每份最多 2000 字符。按完整 URL、frame、区域和字段标识替换同区域重读。超过预算保留遗漏计数，不在重读后恢复成“完整”。
- 本地数字比较要求字段匹配和明确单位。相同名称、相同数值去重并保留多个来源；同名不同值作为冲突排除出确定排名。每个单位提供最高/最低各 20 条；给模型的结构化摘要最多 14000 字符，缩减时保留显式标记，完整来源另随任务结果返回。数字识别失败时说明未解析，不猜测其他百分比。
- 扫描使用有界文本遍历，避免克隆整个正文后再截断；浏览器增量遍历最多 6000 节点，最多返回 80 个元素，其中最多 6 个可读区域。样式和矩形缓存只活跃于本次观察。扫描范围被截断时向模型报告，不宣称观察了全部控件。
- 分段日志包含耗时、候选/返回数量和输入 token 估算，不记录 API Key 或图片字节。模型调用仍逐动作决策，未改成批量自动重放动作。

## 仍需区分的情况

- 各分页使用不同完整 URL 时可以独立累积；同 URL 且复用同一 DOM 区域的分页目前视为重读并替换。虚拟列表只能读取已加载的行，不承诺自动覆盖未加载内容。
- 不是任意网站通用的表格恢复器，也未添加 OCR、画笔/箭头标注、MCP 或通用脚本执行能力。
- 任务内暂停/继续保留图片和区域数据；关闭侧栏后 checkpoint 不存这些正文/图像，检测到缺少图片或区域证据时要求从原消息重新开始。
- 未对用户的配置模型和登录态执行真实 Agent 任务，不承诺具体提速倍数。模型响应速度、网页加载、需执行的步数仍影响整体用时。

## 验证

实现前新增行为回归复现图片未传递、非视觉误启动等问题；验证了图片到达 Gateway、固定模型/来源、停止后迟到结果、唯一回复、重复区域读取、跨页排名保留、冲突与截断，以及后台换文档/撤权/超时拒绝结果。

使用独立浏览器中的合成页面验证框选、确认和取消，以及 240 张卡片、筛选区和 8000 个噪声节点下的读取边界。测试样本包含表格首列为排名、隐藏/编辑节点、整张卡片为链接且名称为普通文本的结构。静态样本在 `tests/fixtures/agent-region-cards.html`，截图预览验证页在 `output/playwright/screenshot-region-picker.html`。

交付前统一运行 `npm run check`。Node 回归、合成页验证和扩展构建不等于所有站点、模型端点和 MV3 生命周期都已实测。
