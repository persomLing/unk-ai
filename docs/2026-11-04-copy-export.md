# 回答复制与回合导出

回答复制按钮打开两种格式选择：Markdown 原文和纯文本。纯文本通过 Markdown token 转换，保留中文、段落、嵌套列表、表格单元格、代码空白和链接地址；公式保留可读的 TeX 内容。菜单固定本次打开的正文，键盘、外部点击和会话重绘可关闭；若消息只有思考内容，会明确提示复制对象为思考过程。

主题按钮右侧新增导出入口，以当前聊天的问答回合为选择单位，可多选和仅保留回答。选择面板和预览共用冻结的数据快照，导出不读取页面、不请求模型、不修改会话或保存队列。生成中的回答导出已有部分并保留状态，原有 Markdown 会话导出维持原路径。

PNG 和 PDF 使用固定 800 CSS 像素宽的浅色文档，中文、表格、代码和公式沿用已有消息渲染规则。预览与成品共用文档和公式适配；导出使用独立文档，移除 Markdown 图片的网络加载，显式的本地栅格附件可嵌入。没有正文的回合、错误、停止和流式状态均有说明，不把不完整结果包装成完整回答。PDF 以图片分页，文字不能直接选取。

## 边界

- 一次最多 50 轮、12 万字符；提问和附件预算只在包含提问时计入。本地图片合计最多 8 MiB。
- PNG 最多高 16000 CSS 像素；画布最多 3200 万像素并维持至少 1.5 倍清晰度。过长或过大时提示减少回合或改 PDF，不截去尾部。
- A4 PDF 最多 40 页，按文字行、表格行、标题和图片布局计算切点。超过单页的元素连续切片，保证内容像素覆盖；PDF 页脚显示页码。
- 每次生成有独立取消信号，依赖加载、字体、图片、截图和下载等待均有截止时间。关闭、超时、切换会话和释放实例后，迟到结果不能更新下一次导出状态或发起下载。
- 浏览器已接受的下载不受本地取消回滚；界面只说明“已交给浏览器保存”，不声称文件已持久化。Blob URL 延迟释放以容纳保存窗口。
- 未增加模型用途、通用工具或独立服务端；主要渲染依赖动态加载，不在普通问答时执行。

## 验证范围

`npm run check` 通过 964 项测试及扩展构建。新增行为测试覆盖纯文本转换、复制归属/超时、非连续选择顺序、白名单快照、预算、取消下载等待和连续分页边界。

使用真实 Chrome 浏览器中的本地模块组合验证菜单两种复制、选择两轮导出 PNG、选择不连续回合且仅保留回答导出 5 页 PDF、空选择禁用、Escape 焦点恢复，以及 320×760、360×400 和明暗主题布局。以可控渲染器验证重复点击、等待中关闭、旧结果、90 秒超时、重试、会话切换和释放后的命令。

另在 320px 宽和严格脚本 CSP 的本地页面验证真实渲染依赖：PNG 成功，4 页 PDF 的 140 行代码跨页连续且保留最终尾部与来源；实际等待中取消返回 AbortError，临时 iframe 清理为零。PNG 和 PDF 的 Poppler 页面图已进行视觉检查，无空白页或文字截行。上述测试覆盖实际渲染和下载产物，不代表所有站点内容、操作系统保存窗口及全部 MV3 生命周期均已实测。
