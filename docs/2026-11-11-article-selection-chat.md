# 回答选区引用与单独追问

选中聊天中助手回答的正文后，选区旁显示“引用到当前对话”和“单独追问这段内容”。跨消息、思考区、输入框和控件的选择不作为文章引用。

“引用到当前对话”先在选区附近打开注释小卡片，可以填写问题或说明，点击勾选或按 Enter 确认，Shift + Enter 换行；空注释表示只引用原文，取消或 Esc 不加入草稿。可以连续引用多段，正文使用淡青高亮和编号，输入框默认用“N 条引用注释”收起汇总，点击汇总或编号可展开清单，修改、移除或清空。已有文字和附件保留，用户发送后才请求模型；未发送的引用仅在当前侧栏内存中，切换会话或关闭侧栏会清理草稿。

本轮按回答引用提问，不自动读取当前浏览器页或进入页面操作。引用不会被迟到的网页选区轮询覆盖，清除引用也不会清除网页上的选择。发送准备阶段短暂阻止修改引用；进入回答生成后仍可为下一问添加引用。所有编辑返回独立副本，已提交回合、队列、重试和回退的引用快照保留自己的原文、注释及来源，旧完成回调不能清掉后来修改的草稿。

“单独追问这段内容”打开可拖动的小窗口，显示引用原文及来源，输入提示为“想了解这段内容的哪一部分？”。拖动标题栏移动窗口，拖动右下角调整宽度与高度，也可聚焦尺寸按钮后用方向键调整。窗口及工具栏受视口边界约束；小窗口内正文单独滚动，支持思考、停止和重试。

点击标题栏收起按钮，或实际向右拖动至少 24px 且窗口右缘距视口右边缘不超过 24px 时，窗口用 260ms 过渡收成右侧对话图标；点击图标展开并恢复原尺寸、位置、焦点及阅读位置，视口变化后仍约束在可用范围内。系统启用减少动态效果时即时切换。收起保留回答、输入草稿及运行中的应用，不触发停止、另建对话或额外保存；多个图标优先使用彼此分开的可用位置。

右侧图标在准备、思考、回答期间显示青绿色旋转光环；思考另有轻微呼吸效果，回答时光环加快，悬停说明对应真实阶段。成功终态提交且正文非空、窗口未展开查看时才产生未读点，忙碌收尾期间仍先显示进行状态。展开且页面可见时清除未读，再收起不重复提醒；后台完成后切回已展开窗口也会清除。停止、失败、仅思考、重复终态或旧回合迟到事件不会作为成功提醒。减少动态效果时用静态光环，未读点没有持续闪动。

顶部跟踪说明和折叠的“选中的原文”保留自身高度，长历史只在消息区滚动；展开原文限制高度并保留可见摘要。最小尺寸使用紧凑间距，提示、引用和底部输入操作保持可见。

同一主对话中的后续“单独追问”复用第一次打开的未分组追问分支，更新下一次发送的原文与相邻语境，并保留已有追问历史及输入文字。正在准备或回答时，新选区作为下一问的独立快照等待；当前回合继续使用提交时的引用，迟到准备结果、完成、停止或重试不会覆盖或消费后来选择的引用。选中内容本身不发送模型请求，接受失败不另建同来源窗口。只有关闭仍在跟踪的追问后，下次单独追问才另建分支。

新建、切换或替换主对话导致主会话 ID 变化时，旧窗口永久解除跟踪并持续显示“已切换主对话；新的选区将另开追问。”旧窗口和回答仍独立保留，可以展开续聊；返回原主对话不会重新附着旧窗口，新的选区另开追问。先清跟踪归属再通知视图，旧窗口迟到的关闭回调只能清理自己，不能清掉新窗口的跟踪。

每个新分支使用新的会话标识，不继承原对话的分组。打开、收起或关闭尚未发送的空窗口不保存空历史；首次发送通过现有保存队列与 outbox 提交完整待写记录，文件夹同步状态单独确认。关闭会停止当前本地等待，已有提问及部分回答保留在未分组历史；未发送的窗口草稿仅在内存中。

点击“替换当前对话”会将该新对话打开到主聊天区，原对话保留。浮窗及主区的任务须先完成或停止。接管前固定主会话与窗口归属，确认必要保存，再释放浮窗应用并交出独立副本；保存失败或外部归属失效不会迟到切换对话，保存等待取消也不代表已排队的磁盘写入被撤销。

从历史中打开仍在浮窗里的同一对话，也使用上述独占接管流程；回答进行中阻止打开，完成或停止后才转入主区。删除仍打开的浮窗对话前须先关闭该窗口，避免保存与删除互相覆盖。最小窗口尺寸下引用和提示可独立滚动，发送、关闭与替换按钮保持可见。

浮窗的来源列表点击外部、滚动回答正文、调整浏览器窗口大小或失去焦点后关闭；来源内部可滚动，来源链接仍遵循默认打开行为。Esc 优先只关闭来源列表并按需把来源链接焦点恢复到展开按钮，后续 Esc 才由其他窗口快捷键处理；消息重绘后清理失效的来源节点及状态。

## 语义上下文与数据兼容

选区同步捕获原回答附近正文、所在小节和原用户提问，固定原会话及消息标识。原文最多 6000 字符，前后正文各最多 2400 字符，合计上下文最多 5000 字符，原提问最多 1200 字符，标题各最多 200 字符；遗漏使用截断标记说明。数据以 `source: conversation`、`sourceVersion: 1` 随既有 `selection` 字段保存；旧网页选区的形状与语义不变。

多处引用使用 `sourceVersion: 2` 的 `annotations` 数组，最多 8 条，引用原文和相邻语境合计最多 16000 字符，每条注释最多 2000、注释合计最多 8000 字符。每条保留 V1 来源及可序列化文字偏移 anchor，原提问及标题继续按单条上限约束；运行时超额明确报错并保留编辑输入，旧记录仍可读取。已发送提问可展开查看全部引用及注释。高亮使用 CSS Custom Highlight API，编号位于独立显示层，正文文本和结构不变；重绘后重新核对原文，无法匹配时隐藏编号但保留资料。

此次追问复用沿用上一版的 V1 引用与既有会话、outbox 和目录绑定格式，不新增持久字段，也不改写历史。单独追问只接受当前主会话来源的有效 V1 选区；主区多处注释继续使用 V2。跟踪窗口、图标状态和未发送草稿只在当前侧栏内存中，侧栏重开不会自动恢复浮窗或根据历史会话重新跟踪。

模型参考资料位于用户消息的 JSON 引用中，回答片段不是当前网页、系统指令或已核验的事实。浮窗只携带选区引用及其后续对话，不读取原会话的完整历史、内部思考或当前网页全文；模型配置在每次提交时冻结。界面重绘会关闭旧工具栏，已提交的追问保持自己的引用快照；新的显式选区更新下一问，不改变旧回合。
