# 0.18.2：引用注释、独立追问与按需联网

日期：2026-11-11。

本版支持围绕回答中的多处原文添加注释，使用独立追问窗口继续研究，并在收起后查看运行与未读状态。联网问答由主模型按需使用搜索、读取工具；同时增加图片缩放拖动、长文本卡片与全文弹窗，修复空对话保存，统一长内容滚动条，补齐操作手册。

## 引用与独立追问

- 选中助手回答正文，可“引用到当前对话”或“单独追问这段内容”。引用可逐条添加说明，原文高亮并编号，输入框汇总后可修改、移除或清空；发送时携带有界的原提问、小节与相邻正文。
- 独立追问使用可拖动、调整大小的窗口。同一主对话后续选区复用仍在跟踪的首次追问；正在回答时新增的选区留给下一次发送，不能改写已提交回合。
- 点击收起或拖到右边缘可缩为图标，保留任务、草稿与阅读位置。准备、思考、回答用青绿色光环提示；思考时轻微呼吸，减少动态效果设置下保持静态提示。
- 成功完成且尚未查看时才显示未读小点，展开查看后清除；再次收起不会重复提醒，停止、失败和迟到事件不产生成功小点。
- 切换、新建或替换主对话后，旧追问解除选区跟踪并显示提示，仍可独立续聊。关闭浮窗会停止本地等待；收起继续执行。“替换当前对话”或从历史打开会将追问转到主区，保留原主对话。
- 空追问首次发送前不进入历史；引用注释和未发送文字是当前界面中的草稿，不宣称已经持久化。

实现、上下文预算与验证入口见[回答选区与单独追问](2026-11-11-article-selection-chat.md)。

## 联网检索与来源核对

启用联网后，第一次主回答请求携带受控搜索和来源读取工具，模型结合问题与已有资料选择直接回答、搜索或补读，再继续同一条主回复。旧的独立联网判断与预抓取不再用于普通主回答；页面和附件的准备规则保留。

每轮最多 4 轮工具、6 次不同操作、3 次不同搜索，同批并行最多 2 项，工具累计等待 45 秒。重复查询或来源复用本轮结果，不重复扣次数；每次模型请求获知剩余额度。正常耗尽预算后，执行器返回未派发的明确原因，再依据已有资料收尾；必要工具失败、权限拒绝、实际超时和取消仍保留可见状态。

来源列表区分“搜索摘要”“已读正文”和未知状态，不把摘要或网站图标当作通读证明。网站图标缺失或失败时使用地球图标，来源链接仍可打开。追问的来源列表在点击外部、滚动、调整窗口、失焦或按 Esc 时关闭。

设置可配置服务搜索与抓取接口。仅确认 404/405/501 表明接口缺失后使用有界公开回退；认证、权限、限流或超时不会触发回退。主回答仍要求模型服务支持流式工具调用，不支持时明确报错。范围见[模型驱动检索](2026-11-09-model-driven-research.md)。

## 阅读体验与保存

- 图片附件和消息缩略图可点击或通过键盘打开预览。滚轮以鼠标位置为中心缩放，左键或单指拖动查看超出视野的内容；工具栏提供缩放比例、加减按钮、适应宽度和原始尺寸。双击切换尺寸，方向键平移、＋/－缩放、0 复位；关闭按钮、遮罩和 Esc 可退出，切换对话自动关闭。
- 主聊天与独立追问中，纯文本粘贴达到 1000 字符或 15 行后显示为卡片，可查看全文、编辑或移除。最多折叠 6 段、粘贴文本合计 20 万字符，超限明确提示；发送时按原插入位置合并为完整提问，不新增文档附件或持久字段。
- 发送后的长提问按实际显示高度折叠为五行，点击或键盘打开全文弹窗；宽度足够且全文能容纳时自动取消折叠。原文继续用于发送、排队、复制、保存和回退，选中文字不会误开弹窗。
- “下一步探索”根据本轮问题、结论与来源状态生成具体追问，排除陈述段落、泛指内容与回答摘录；没有合适推荐时不凑数量，辅助失败不阻塞主回复。点击推荐直接发送，欢迎页话题卡仅填写草稿。
- 顶部和分组内新建对话在首次提交前保持临时状态。切换对话不会保存空记录，只输入文字或添加引用不算提交；组内首次保存仍保留目标分组。
- 聊天、历史、思考、表格、追问和设置共用滚动条颜色。内容溢出时，鼠标移入对应区域或键盘聚焦才显示，移出隐藏；触屏和高对比度保留必要提示。粗细按使用场景调整，显隐不挤动正文。

本次同时包含 Agent 动作边界修复：实际派发前重新核验任务许可，取消和迟到结果维持原任务归属，框架及开放 Shadow DOM 的扫描和动作核对沿用受控边界。具体覆盖及尚未实现的范围见[Agent 边界修复](2026-11-06-agent-boundary-fixes.md)。

## 手册、升级与交付

[操作手册](USER-GUIDE.md)与[离线 HTML 阅读版](USER-GUIDE.html)同步更新为 0.18.2，包含 13 章、16 幅截图与流程图。新增五分钟上手、场景索引、操作步骤、状态对照、引用与追问图解、联网证据图解、FAQ、快捷键及完整示例。HTML 内嵌图片与样式，窄屏宽图和表格可在区域内滚动。

升级时保留原扩展安装和数据目录，先结束运行任务并确认保存，再将 `unk-ai-v0.18.2.zip` 解压到原扩展目录，重新加载扩展并重开侧栏。ZIP 根目录直接包含 `manifest.json`；源码用户继续加载 `dist/`。按需刷新之前打开的网页，核对扩展卡片版本为 0.18.2。

本版不清除旧对话、模型设置、分组或待同步记录。正式会话继续通过现有存储队列与 outbox 保存，保留版本确认和原目录绑定；备份时一起保留 `conversations/` 与 `images/`。未发送草稿不属于持久化会话，更换文件夹不会迁移旧记录。

开发者修改手册后运行 `npm run docs:build`；发布前运行 `npm run check` 并提交代码，再以 PowerShell 7 执行 `scripts/package-release.ps1`。打包脚本要求工作区干净，检查版本、入口与 ZIP 逐文件 SHA-256，并记录提交号、文件清单和安装包哈希到 `output/package-v0.18.2-validation.json`。该记录与安装包独立于源码提交，手册单独提供。
