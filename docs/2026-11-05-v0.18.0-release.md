# 0.18.0：历史分组与设置页改版

日期：2026-11-05。

本版整理历史会话的操作方式，重做设置页，并明确当前页问答的读取范围。

## 当前页问答

- 开启“基于当前页”后，普通页面提问必须成功读取本页再回答；必要正文读取失败会明确报错，不使用旧正文代替。
- 切换网页保留本次侧栏会话中选择的模式，开启时来源跟随新页；已经发送、排队和重试的问题仍绑定各自原页面。
- 关闭开关后按普通问题处理。明确询问网页时提供读取选择；“页面操作”须先开启页面开关，并继续遵守原有站点授权。

## 历史会话

- 新增单层可折叠分组、组内新建与全局新建。对话可长按拖入另一分组，悬停折叠组会展开，Esc 可取消。
- 分组和对话支持右键或「⋯」菜单，名称在原位置编辑。行内操作按钮在悬停或键盘聚焦时显示；“全部对话”保持平铺。
- 「⋯ → 选择多个」提供批量移动和删除，每批删除最多 200 条。搜索和折叠保留选择，并提示隐藏的已选项目。
- 操作提示 3 秒后自动收起，可点「×」关闭；悬停或聚焦暂停计时。删除恢复入口保留在「⋯ → 撤销上次删除」，移动与改名不再附带旧的删除按钮。

## 设置页面

设置分为连接服务、模型库、生成参数、联网检索、本地数据和浏览器控制。桌面侧边导航与小屏横向导航使用同一表单，底部固定保存栏显示未保存状态，支持明暗主题。

获取模型与编辑已有模型分开。切换模型保留各自参数草稿，保存时校验所有模型并定位错误；连接信息改变后，旧请求结果不能覆盖新配置。“测试连接”只验证当前填写的配置，不自动保存，也不读取网页。模型配置通过保存按钮提交，文件夹和浏览器权限操作立即生效。

## 数据兼容与升级

旧历史默认位于“未分组”，升级不重置现有会话或配置。分组归属、自定义名称和列表偏好保存在当前浏览器，不改变磁盘文件布局。删除分组只把对话移到“未分组”。

删除对话会删除原目录中的真实文件，并先在浏览器 IndexedDB 保留完整恢复记录。撤销沿用原目录绑定；文件删除结果未确认或恢复后尚未同步时会明确提示，不能把列表变化当成磁盘操作已成功。关闭提示不会清除恢复记录。

加载项目 `dist` 的用户，在 `chrome://extensions` 重新加载扩展；ZIP 用户解压 `unk-ai-v0.18.0.zip`，加载包含 `manifest.json` 的目录。更新后刷新需要读取的网页。

## 验证范围

本次发布前重新运行 `npm run check`，1090 项测试全部通过，Vite 构建成功。浏览器已完成设置页 20 项、历史提示 14 项交互检查，使用模拟 Chrome API，并在历史存储检查中使用真实 IndexedDB。这些检查不代表全部站点、线上模型服务或完整 MV3 生命周期均已实测。

`package.json`、锁文件、源码及构建清单中的版本均为 0.18.0。ZIP 的 277 个文件已逐一校验大小与 SHA-256，全部匹配 `dist`；清单位于包根目录，引用的入口、脚本、图标和语言资源齐全。
