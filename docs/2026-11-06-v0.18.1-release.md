# 0.18.1：固定会话标题、宽屏历史与统一导出入口

日期：2026-11-06。

本版把整段会话 Markdown 导出移入顶栏下载菜单，让当前对话标题保持可见，并在宽屏并排显示历史区；同时打包本次排障中的复制、附件回退、Agent 感知与图片存储改动。

## 会话标题与导出

- 顶栏下载菜单现在提供“图片 / PDF”“Markdown”和“诊断日志”。图片 / PDF 沿用回合选择与预览，Markdown 沿用整段会话格式，诊断日志仍是本对话今天（北京时间）的记录。
- 当前会话标题固定在工具栏上方，消息滚到底部时仍可见。过长标题单行省略，悬停查看全文；新对话不显示额外标题行，保留默认“UNK AI - 阅读与对话”。
- Chrome 原生侧栏头由浏览器绘制，[sidePanel API](https://developer.chrome.com/docs/extensions/reference/api/sidePanel#type-PanelOptions) 没有动态标题字段，因此会话标题位于原生头正下方，不能替换浏览器绘制的名称。扩展页面自身的 document.title 会同步当前会话。
- Markdown 在普通生成、Agent 任务、提交、压缩或任务重启期间禁用，保持原入口的忙碌规则。点击时固定内容和文件名，保存等待有 60 秒上限并阻止重复导出；切换会话或释放页面会取消本地等待，旧结果不会更新新会话提示。已交给浏览器的下载仍需在浏览器下载界面管理。

## 宽屏历史区

侧栏页面可用宽度达到 960 像素时，历史区自动常驻左侧，与对话并排显示；收窄后恢复覆盖式抽屉。宽屏可手动收起历史区，再用顶部历史图标展开。宽屏切换或新建对话时保留历史区，不重新创建列表；首次自动展开不抢输入框焦点。并排模式为 360 像素历史区和至少 600 像素对话区，沿用同一份搜索、分组和列表状态。

## 本次排障改动

提问气泡到下方复制、回退按钮之间的连续悬停与命中已修复，右侧轮次导航的透明区域不再遮挡点击。回退编辑会同时恢复问题文字、图片、文档和选区；原任务重启继续校验页面身份、任务状态、附件和许可。范围见[任务重启与附件回退](2026-11-06-message-restart-rewind.md)。

Agent 写任务增加有界的无进展恢复，局部视觉判断可读取当前控件附近画面，再进入现有受控动作决策。透明标签和文件输入仍须可见区域与命中校验，上传仍保留逐次确认。范围见[页面感知与复制修复](2026-11-06-agent-perception-and-copy.md)和[透明控件修复](2026-11-06-agent-transparent-controls.md)。

最新上传故障出现在网站接收参考图后清空 FileList 的核验阶段，任务尚未提交生成点击。插件现在独立核对本次新出现、与原参考图内容匹配的局部预览；结果不明不重传，不把本地预览声称为服务器处理完成。范围见[上传接收核对与图片存储](2026-11-06-upload-receipt-and-image-files.md)。

## 图片与旧数据

正式会话图片保存在所选本地数据目录的 images/ 中，conversations/ 下的 JSON 记录图片相对路径和存储版本，不内嵌 Base64。旧内嵌记录仍可打开，下次正常保存时转换；内存与未同步浏览器记录保留可恢复像素，模型请求按服务接口要求传图。

图片写完后才替换会话 JSON，失败保留待同步记录、版本和原目录绑定。缺图或损坏时显示具体原因，需要该图的发送、重启和导出明确报错。共享图片暂不自动清理，移动或备份会话时需一起保留 conversations/ 与 images/。升级不重置历史会话、分组或模型配置。
