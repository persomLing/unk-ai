## 范围与兼容

- 本次没有修改流式协议、Agent 动作许可、主回复终态或会话文件保存链路。
- 全局话题仍使用用户配置的模型；扩展没有新增独立全网搜索服务，不能把模型生成的时事回答当作已由扩展联网核验。
- 用户主动添加的附件仍保留。独立话题会退出页面操作模式并清除此前选区；显式开启页面开关可以重新带上当前页。
- 旧会话的来源和阅读策略不批量重写。重试仍保留原范围；建议重新点击新闻话题，或重新提交当前页问题来使用新规则。
- 当前章优先的空章节计划在重试时仍保留，不重新把本章标成“目录中未读”。纯定位已有目录匹配时，不依赖额外目录下载成功；明确比较多个主题时，各主题章节仍可匹配。
- 不删除历史消息、改变存储目录或覆盖此前交付的 ZIP。
