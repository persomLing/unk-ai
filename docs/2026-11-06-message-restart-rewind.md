# 任务重启与附件回退

2026-11-06，修复失败任务的重启入口在离开可读页面时直接禁用、无法说明原因，以及回退提问只恢复文字而丢掉附件的问题。修改复用既有提交、Agent 执行和会话保存边界，没有添加另一套生成流程。

## 重新开始任务

`agent-task-restart.js` 为每次重启固定原会话、用户提问、失败回答及原页面来源。空闲状态下按钮保持可点击，页面开关关闭、当前独立话题或其他阻止条件会给出具体原因；运行或准备中仍阻止重复操作。

如果记录中的原标签仍打开且完整 URL 一致，可从无关标签或不可读页面返回原标签，在同一浏览器窗口重新捕获当前文档目标。重启携带原提问附件的独立副本，调用既有提交入口建立新 Agent 任务并重新观察；不会续播旧动作清单，也不重新授予后台执行权限。原截图的来源信息仍须通过既有校验，不能因重启而改绑文档。

原标签关闭、完整 URL 变化或旧提问缺少有效任务模式/来源时，提示回退原提问，保留图片后在用户选择的目标页面重新发送。程序不自动新开标签、不改绑相似网址或同名页面；原任务位于另一浏览器窗口时，提示从原窗口打开侧栏。原消息和图片在准备失败时保持。

准备等待有时间上限；重复点击只接受一次。停止、切换会话或页面许可变化后，迟到查询和截图不能激活后续模式或启动模型/页面任务。已经执行或已经送出的动作仍遵循原有取消语义，不能把停止等待解释为从未执行。

准备重启期间，普通发送、Enter 和普通重试入口均被阻止，保留当前草稿；重启自身经过原页校验后才进入同一个 ConversationService。关闭页面开关会同步取消重启等待和仍在准备的提交。

## 回退并重新编辑

`message-rewind.js` 在截断分支前捕获原提问，并深克隆其图片、文档正文和选区。显示文字与独立话题来源意图一并恢复到当前输入框，旧提问及其后续消息移除。克隆保留图片的 `dataUrl`、元数据及截图的标签页、完整 URL、文档和视口来源；编辑草稿不会修改被捕获的原附件对象，也不会把截图重新绑定到当前页面。

旧文字消息没有附件或选区时，会清空当前无关草稿中的附件和选区，不把两份问题混合。准备附件、生成、提交、压缩、浏览器任务及历史整理中阻止回退。恢复会取消原待选来源提示，并清除旧问题的短期重复提交指纹。

回退保存通过已有会话保存器固定原会话，最多等待 10 秒；失败或超时保留已恢复草稿并显示错误。迟到保存不会覆盖另一会话的草稿附件或补发旧界面完成提示；已经进入存储队列的写入仍由原队列和目录版本规则处理。

## 提问中的图片保存在哪里

- 上传或粘贴后、发送前，图片首先位于当前侧栏草稿内存。较大的图片可能先被缩放或压缩。
- 发送后，当前会话和模型请求仍使用用户消息的 `attachments[].dataUrl`。正式磁盘保存会先将像素写入所选数据根目录的 `images/<SHA-256>.<格式>`，再在 `conversations/<会话id>.json` 中写 `imagePath` 与 `imageStorageVersion: 1`，不再内嵌 Base64。打开旧内嵌记录仍兼容，下一次正常保存时转换。
- 打开正式会话时，仅对该会话的路径图片读回内存；缺失、损坏或授权失效显示附件错误，不能静默丢图重启或发送。落盘前及文件夹同步失败时，IndexedDB outbox 保留完整待写像素，并绑定原目录。删除会话保留共享图片，避免破坏其它引用与撤销。
- 临时会话保存在扩展 `chrome.storage.local` 的 `temporaryConversation` 项中。
- 回退后的附件恢复到当前侧栏草稿内存。现有草稿没有独立持久化协议，恢复到输入框不等于新草稿已经保存；关闭侧栏前需重新发送或另行保留需要的内容。

插件读取原上传文件后保存自己的图片数据，不移动或删除原磁盘文件。诊断日志不保存这些图片像素；导出的 PNG/PDF 是另一份用户选择的可见内容快照。

## 验证范围

行为回归为 `tests/message-rewind.test.js` 与 `tests/agent-task-restart.test.js`，覆盖附件深克隆、缺少附件的旧消息、忙碌阻止、固定会话、保存错误/超时/迟到结果、原标签/完整 URL、新文档捕获、重复点击、取消与旧记录缺失提示。发送、Agent、会话保存仍使用相关既有组合回归；整体交付使用 `npm run check`。

最终 `npm run check` 通过：1463 项测试全部通过，Vite 构建成功，`dist` 已更新。原生 Chrome 侧栏另通过 `tests/browser/message-restart-rewind-native-extension.js` 验证：从无关/不可读活动标签点击重启，准确返回原标签、重新捕获文档，1 次 Agent 请求包含原 PNG；关闭页面开关后点击可见原因且不发模型请求；回退后恢复图片和文字，普通重新发送的 1 次主请求包含原 PNG，保存后仅有 1 条用户提问及原图。额外 1 次建议问题请求单独统计。

原生侧栏使用实际构建的 `sidepanel-BZ_eKIQC.js`，保留真实 sender 校验、后台许可、标签页/文档、DOM 观察和浏览器存储，仅网站 HTML 与模型响应为本地替身。验证记录为 `output/playwright/message-restart-rewind-native-validation.json`。这些验证不能代表用户原网站的上传、生成服务或模型供应商已经实测；重启入口正确也不能解决模型服务再次返回空动作的问题。
