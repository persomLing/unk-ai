# UNK AI 二期需求：受控浏览器 Agent

> 版本：Phase 2 / 2026-10-29  
> 基线：0.14（只读阅读 Copilot：网页/PDF 读取、结构化理解、视觉截图、上下文压缩）  
> 参考：本机安装的 ChatGPT Chrome 扩展 1.26.1020.11845（仅借鉴能力与交互，不复制其代码、文案或资源）  
> 性质：需求与验收基线，不代表当前已实现

## 0. 结论

二期要把 UNK AI 从“能看会答”升级为“能控制页面、并对每一步负责”的受控浏览器 Agent。

安全权限按 ChatGPT 扩展的可见能力对齐，而不是只加一个“确认弹窗”：

1. **全局浏览器控制授权**：默认关闭，用户显式开启。
2. **按站点授权**：每个 origin 单独授权，可仅本次任务、可始终允许、可随时撤销。
3. **高危动作逐次确认**：提交、发送、删除、发布、下载、关闭用户标签等必须用户确认；支付/下单/密码类动作直接阻断。
4. **人工接管**：用户随时可以暂停并接管页面；恢复必须重新观察，不能沿用旧快照。
5. **凭据与验证码边界**：不自动输入密码、CVV、PIN，不绕过 CAPTCHA/人机验证，遇到即暂停并交给用户。
6. **轮次释放与标签归属**：任务结束释放浏览器控制；代理创建的标签自动清理，用户标签未经确认不关闭，可标记为“留到下一轮/作为交付物”。
7. **全程审计**：每一步动作、目标、风险、授权结果和关键截图本地留痕，可导出。

技术上做一个明确取舍：**借鉴 ChatGPT 的能力面与权限模型，但不照搬它的云端大脑、任意 JavaScript 内核、历史/书签等广域权限**。我们使用本地 BYOK 模型 + 类型化工具协议 + 确定性安全门。这样更符合本项目的本地优先定位，也更容易审计。

## 1. 目标与非目标

### 1.1 目标

- 用户用自然语言下达目标，Agent 能观察当前页、点击、输入、滚动、导航、切换代理标签，并完成多步任务。
- 每一步都能看到“为什么做、对哪个元素做、结果是什么”，失败可恢复，危险动作可拦截。
- 达到 ChatGPT 扩展同类产品的**安全可感知能力**：授权、确认、接管、停止、证据、凭据与验证码边界。
- 不破坏现有阅读/PDF/对话能力；浏览器控制默认关闭，按需启用。

### 1.2 非目标（P0 明确不做）

- 不自动完成支付、下单、充值、转账、订阅等资金操作。
- 不自动填写密码、CVV、PIN、验证码，不绕过人机验证。
- 不在侧栏关闭或用户停止后继续后台操作页面。
- 不默认支持任意站点的无人值守长任务。
- 不向模型暴露原始 CDP 或任意 JavaScript 执行能力。
- 不读取历史记录、书签、剪贴板（P1 再评估）。
- 不做文件上传/下载自动化（P1 再评估）。
- 不做多窗口、标签组、无痕模式。
- 不操作 Chrome 内部页、扩展页、应用商店、PDF 阅读器；PDF 仍只读。
- 不做云端同步、远程浏览器、MCP/WebMCP（P2 再评估）。

## 2. 参考基准与取舍

### 2.1 从 ChatGPT 扩展借鉴什么

| ChatGPT 扩展能力 | 我们的对应设计 | 优先级 |
|---|---|---|
| 全局 `allow_browser_control` 授权 | 设置页/首次任务开启浏览器控制，默认关闭 | P0 |
| 按 origin 的 `access_browser_origin` | 按 origin 授权：仅本次任务 / 始终允许 / 拒绝；可撤销 | P0 |
| 高危动作确认、Guardian/approvals | 确定性风险分类 + 逐次确认；不实现服务端 Guardian | P0 |
| 用户接管 `requestUserTakeover` | 暂停并接管、释放 CDP、恢复前重新观察 | P0 |
| 标签 claim/handoff/deliverable、租约 | 代理标签/用户标签分离，任务结束释放；留到下一轮/作为交付物 | P0 基础，P1 完整 |
| AX + 可见 DOM + Playwright locator + 坐标 CUA | AX/DOM 为主，语义 locator 兜底；坐标兜底放 P1 | P0/P1 |
| 虚拟剪贴板、contenteditable 输入 | 用 CDP 聚焦 + 全选 + `Input.insertText`，不依赖系统剪贴板 | P0 |
| 每步截图/证据留存 | 高危动作前后与最终结果截图，本地审计日志 | P0 |
| `turn_ended` 释放控制 | 任务结束/取消统一释放 debugger，禁止自动重连 | P0 |
| 凭据/验证码/反自动化边界 | 密码类硬阻断、登录/验证码暂停接管、检测即停 | P0 |
| 任意 JS Kernel、MCP/WebMCP、历史/书签、云浏览器 | 不照搬；JS Kernel 与 MCP 放 P2 评估 | P2 |

### 2.2 不照抄的部分

- **不做任意 JS 执行**：ChatGPT 扩展的 `js` 工具表达力很强，但模型生成代码会绕过类型化安全门。P0 只暴露受限工具；P2 若要做，必须是带类型 SDK、白名单 API、独立沙箱的受控 Kernel。
- **不做云端大脑**：它的规划在服务端；我们必须在本地用自己的模型实现决策循环。
- **不扩大权限面**：历史、书签、剪贴板、文件路径、原生消息在 P0 都不需要。
- **不复制代码与品牌**：只借鉴能力集合和交互模式，界面使用 UNK AI 自己的语言与组件。

## 3. 能力范围

### 3.1 P0（必须）

- 观察：当前页快照、可交互元素清单、页面摘要、按需截图、iframe/开放 Shadow DOM。
- 操作：点击、输入、按键、滚动、选择、导航、打开/切换/关闭代理标签。
- 等待与校验：加载状态、URL 变化、DOM 稳定、目标元素存在/可见/未被遮挡。
- 安全：全局授权、origin 授权、高危确认、人工接管、停止、密码/支付硬阻断、验证码暂停、审计与截图。
- 会话：单任务多步、最大步数/时间、停滞检测、检查点、恢复暂停。
- 兼容：支持 OpenAI tools 的模型优先；不支持时走严格 JSON 动作协议。

### 3.2 P1（应做）

- 接管用户已有标签（claim）与多标签切换；标签保留/交付物。
- 文件上传（用户选择文件）、下载（确认后）、剪贴板读写（单独授权）。
- 语义 locator 完整化（role/name/label/text/testid）与坐标兜底。
- 轨迹记忆压缩、错误重试策略、卡死检测增强。
- 站点权限管理、按站点审计筛选。

### 3.3 P2（评估）

- 受控 JS Kernel / Playwright 风格 API。
- MCP/WebMCP、浏览器会话命名、云端/本地多浏览器。
- 跨标签对比、长任务持久化、定时任务。
- 真实任务评测集与自动回归。

## 4. 授权与安全

### 4.1 四层权限模型

| 层级 | 作用 | 默认 | 存储 |
|---|---|---|---|
| 全局开关 | 是否允许 UNK AI 控制浏览器 | 关闭 | `chrome.storage.local` |
| 站点授权 | 是否允许控制某个 origin | 未授权 | `originGrants[origin]` |
| 动作确认 | 高危动作是否执行 | 逐次询问 | 任务内临时 |
| 执行器硬阻断 | 密码、支付、验证码、受限页 | 永远阻断 | 代码内规则 |

任何一层拒绝，执行器都必须在发出 CDP 命令前返回错误；**安全判断不能依赖模型**。

### 4.2 站点授权

- 作用域：P0 使用精确 origin（scheme + host + port），子域单独授权。
- 选项：仅本次任务 / 始终允许此站点 / 拒绝。
- 跨域导航：目标 origin 未授权时暂停并询问，不自动跟随。
- 撤销：设置页列出已授权站点、最近使用时间和撤销按钮；撤销后立即终止正在使用该站点的任务。
- 全局关闭：所有动作拒绝，阅读功能不受影响。
- 浏览器仍然声明 `<all_urls>`；应用层的 origin 授权才是实际闸门，设置页必须明确说明这一点。

### 4.3 动作风险分级

| 级别 | 示例 | 处置 |
|---|---|---|
| `normal` | 滚动、点击普通链接、在非敏感输入框输入、页内导航 | 在已授权 origin 内直接执行 |
| `confirm` | 提交/发送/保存/发布、删除/移除、下载、关闭用户标签、未知表单提交、回车提交 | 每次弹窗确认，默认焦点在“取消” |
| `blocked` | 密码/CVV/PIN、支付/下单/充值、账号注销、验证码/人机验证、浏览器内部页、任意 JS、任意本地文件路径 | 不执行；提示并转人工 |

- 风险由内容扫描器根据元素文本、角色、`type`、`autocomplete`、表单上下文、链接 origin 预先标注；执行器必须重新计算，不能信任模型参数。
- 支付/下单：直接阻断，提示用户在浏览器中手动完成。
- 删除/移除：确认后执行一次；不提供“始终允许”。
- 提交/发送：显示目标文本、页面 origin、动作和截图；“允许一次”或“取消”。
- 搜索表单：如果角色为 search 且无密码/支付上下文，可按普通动作处理；无法判断时按 `confirm`。
- 回车提交：默认阻断；用户确认后才允许 `pressEnter` 触发表单。
- 页面中的指令、按钮文案“忽略之前的规则”等，不能改变授权或工具策略。

### 4.4 人工接管

- 用户随时可以点“接管”：Agent 在下一个安全点停止，释放 debugger，页面归用户控制。
- 接管后 Agent 不再观察/操作页面，直到用户点“继续任务”。
- 继续任务必须重新 `observe_page`，旧快照作废；若 origin 授权已过期，需要重新授权。
- 遇到登录、2FA、验证码、原生凭据输入：自动暂停并显示接管提示；不读取输入框当前值。
- 用户完成登录后，恢复前重新观察；如果页面仍在登录流程，不自动继续。

### 4.5 凭据与验证码

- 密码、CVV、PIN、支付密码字段：`blocked`，绝不输入、不读取已填值。
- 登录页：允许观察页面结构，但不自动填写敏感字段；需要登录时交给用户。
- 验证码/人机验证：检测到即暂停；不尝试 OCR、绕过、第三方打码。
- 检测信号包括：`type=password`、`autocomplete=current-password/new-password/cc-csc`、字段名/标签含 password/passwd/cvv/cvc/pin、验证码 iframe/常见挑战文本、站点返回的反自动化页面。
- 如页面要求保护性操作，记录“已阻断”并向用户说明，不把原始错误抛给用户。

### 4.6 停止与中止

- 侧栏“停止”按钮在任何状态可用。
- 触发后设置全局 `isCancelled`，中止当前 CDP 命令，立即 `chrome.debugger.detach()`，禁止自动重连。
- 最多 500ms 内停止；已执行的不可逆动作不得再次自动重试。
- 任务结束后释放 debugger、清理待确认动作；代理标签按规则关闭或保留。

### 4.7 审计与证据

- 每个任务记录：taskId、目标、origin、开始/结束时间、步骤、动作、目标元素、风险级别、确认结果、执行结果、错误码。
- 关键动作前后截图；截图与日志只存本地，最多保留 N 个任务，可一键清除。
- 输入内容只记录字段标签和字符数量，不记录密码；普通文本是否记录由设置决定，默认不记录原文。
- 用户可导出 Markdown 任务报告；导出不包含 API Key、密码或原始页面隐私内容（除非用户主动勾选截图）。
- UI 时间线必须能回答：Agent 做了什么、为什么、谁批准的、结果如何。

### 4.8 威胁模型

- 网页提示词注入：页面文本只作为不可信观察材料；工具参数由执行器校验；授权只能由用户授予。
- 错误点击/布局漂移：执行前校验连接性、可见性、位移、遮挡；失效必须重新观察，禁止盲点坐标。
- 重复提交/重复下单：动作幂等键 + 确认一次 + 禁止自动重试不可逆动作。
- 跨域数据外带：origin 授权 + 跨域导航确认 + 阻断页面内自动提交到未授权 origin。
- 凭据泄露：密码类硬阻断 + 不读取值 + 日志脱敏。
- 扩展被页面脚本操纵：内容脚本隔离、参数白名单、不执行页面传入的代码。

## 5. 任务状态机与会话

### 5.1 状态

```text
IDLE
  ↓ 用户提交目标
OBSERVING → DECIDING → WAITING_APPROVAL → ACTING → VERIFYING
                    ↑                         │
                    └──────── 继续循环 ────────┘
  ↘ PAUSED_HUMAN（接管/登录/验证码）
  ↘ PAUSED_RECOVERY（扩展重启）
  ↘ FINISHED / FAILED / CANCELLED
```

- 同一时刻只允许一个任务、一个原子动作。
- 每步保存检查点：taskId、stepIndex、origin、snapshotId、pendingAction、actionId、lastObservation 摘要。
- 默认最大 20 步、最长 5 分钟；连续 3 次无进展或相同动作重复 3 次判定卡死。
- 扩展重启/Service Worker 被回收后进入 `PAUSED_RECOVERY`；**禁止自动重放上一步**，要求用户核对页面后继续。
- 任务结束：释放 debugger，清理待审批动作，按标签所有权关闭或保留。

### 5.2 执行位置

P0 采用 **SidePanel 编排、Background 执行**：

- SidePanel：任务输入、模型决策循环、审批 UI、时间线。
- Background：CDP、标签管理、内容扫描、安全门、检查点。
- 侧栏关闭 = 任务暂停并释放控制；不允许后台继续点击。
- P2 再评估“后台持久任务”，不要为了长任务在 P0 引入复杂的 SW 保活。

### 5.3 标签所有权

- 区分 `agent` 标签与 `user` 标签。
- Agent 新建的标签在任务结束后默认关闭；用户明确标记“作为交付物”才保留。
- 用户已有标签：P0 不主动接管；P1 支持经用户授权的 `claimTab`。
- 任何情况下不得未经确认关闭用户标签。
- 任务结束后把控制权、滚动位置和标签交还用户。

## 6. 工具协议

### 6.1 模型接口

- 优先使用 OpenAI 兼容的 `tools` / `tool_calls`；流式增量聚合后再执行。
- 不支持工具调用的模型，使用严格 JSON 动作协议：
  ```json
  {"action":"click_element","args":{"snapshotId":"snap_...","elementId":"elem_3"},"reason":"打开第一条结果"}
  ```
- 每次只允许一个动作；参数必须通过 JSON Schema 校验；非法输出重试一次，仍失败则 `fail_task`。
- 模型上下文只包含：目标、origin、允许的工具、最新观察摘要、最近 N 步结果、压缩后的历史；不发送完整 DOM。

### 6.2 P0 工具

| 工具 | 作用 | 风险 |
|---|---|---|
| `observe_page` | 返回 snapshotId、页面摘要、可交互元素、风险标记；按需截图 | 只读 |
| `click_element` | 按 snapshotId + elementId 点击 | 按目标风险 |
| `type_text` | 向非敏感输入框输入；`submit` 默认 false | confirm/blocked |
| `press_key` | 允许的按键；回车默认需确认 | confirm |
| `scroll_page` | 页面/元素滚动 | normal |
| `select_option` | 原生 select 选择 | normal/confirm |
| `navigate` | 在已授权 origin 内导航 | confirm |
| `open_tab` / `switch_tab` / `close_tab` | 代理标签管理 | close 需确认 |
| `wait_for` | 等待 URL/加载/DOM 稳定/元素出现 | 只读 |
| `request_human_handoff` | 暂停并请用户接管 | 只读 |
| `finish_task` | 汇总结果与证据 | 只读 |
| `fail_task` | 报告失败原因 | 只读 |

P1 再加：`list_tabs`、`claim_tab`、`upload_file`、`download_file`、`read_clipboard`、`write_clipboard`。  
**不向模型暴露** `tab_cdp_call`、任意 `js`、文件系统路径、浏览器历史/书签。

### 6.3 结果与错误

统一响应：

```json
{
  "success": true,
  "actionId": "act_...",
  "action": "click_element",
  "data": {},
  "error": null,
  "message": "已点击"
}
```

错误码至少包括：

- `ERR_CONTROL_DISABLED`
- `ERR_ORIGIN_NOT_ALLOWED`
- `ERR_SNAPSHOT_EXPIRED`
- `ERR_ELEMENT_NOT_FOUND`
- `ERR_ELEMENT_MOVED`
- `ERR_ELEMENT_OCCLUDED`
- `ERR_ELEMENT_DISABLED`
- `ERR_SAFETY_BLOCKED`
- `ERR_CREDENTIAL_BLOCKED`
- `ERR_HUMAN_REQUIRED`
- `ERR_PAGE_RESTRICTED`
- `ERR_ABORTED`
- `ERR_TIMEOUT`

执行器不得自动重试不可逆动作；快照过期/元素移动只能返回错误，由模型重新观察。

## 7. 观察与定位

### 7.1 快照内容

```json
{
  "snapshotId": "snap_...",
  "url": "https://example.com",
  "title": "Example",
  "viewport": {"width": 1280, "height": 800},
  "elements": [{
    "elementId": "elem_3",
    "role": "button",
    "name": "搜索",
    "tag": "button",
    "type": "submit",
    "frameId": 0,
    "bounds": {"x": 120, "y": 80, "width": 64, "height": 32},
    "disabled": false,
    "checked": null,
    "risk": "normal"
  }],
  "textSummary": "页面标题、主要段落摘要（截断）"
}
```

- 只返回可交互或对理解任务必要的元素；默认不含输入框当前值，密码字段永不含值。
- `risk` 由扫描器根据元素属性/文本/表单上下文标注，执行器重新校验。
- 支持开放 Shadow DOM；closed Shadow DOM 不可访问时标记为不可操作，不猜测。
- iframe：包含 `frameId` 与绝对坐标；跨域 frame 通过 host 权限注入或 CDP AX 汇总。

### 7.2 定位优先级

1. `snapshotId + elementId`（内容脚本保存真实 `elementRef`）
2. 语义 locator：role + name、label、placeholder、text、testid（P1 完整）
3. 扫描器生成的稳定 CSS（P1，仅作兜底）
4. 坐标（P1，仅用于 canvas/图表等无 DOM 元素；必须截图并二次确认）

P0 不允许模型直接传任意 CSS 选择器或坐标；所有目标都通过快照 ID 解析。

### 7.3 执行前校验

- `elementRef.isConnected`
- 可见性（`display/visibility/opacity`）
- 未被禁用
- 当前 bounds 与快照偏差 ≤ 8px
- 中心点 `elementFromPoint` 未被其他元素遮挡
- 目标是否在新页面/新 frame

任何一项失败都返回对应错误，要求重新观察，不执行“近似点击”。

### 7.4 观察预算

- 默认只发元素清单 + 页面摘要；截图按需（视觉问题、坐标兜底、高危证据）。
- 观察文本有字符上限；超出时优先保留标题、URL、表单、按钮、链接和风险元素。
- 复用现有 `auto-visual` 的模型判断逻辑，但截图必须按预算和用户设置。

## 8. 执行器与 CDP

### 8.1 输入

- 点击：滚动到可见 → 重新校验 → CDP `Input.dispatchMouseEvent` 按下/抬起；点击后等待稳定。
- 输入：聚焦 → 全选/清空 → `Input.insertText` → 读值校验；兼容 contenteditable。
- 回车：默认不发送；仅在用户确认提交或显式 `press_key` 且风险通过后发送。
- 按键：只允许 Tab、Escape、方向键、Backspace、Delete（非删除业务）、Enter（受控）；禁止浏览器快捷键、地址栏、开发者工具快捷键。
- 滚动：优先 CDP 鼠标滚轮；失败时对目标容器执行受控滚动。
- 选择：原生 `<select>` 用 DOM 赋值 + change 事件；自定义下拉用点击 + 观察选项 + 点击选项。
- 导航：只允许 http/https 且 origin 已授权；禁止 `javascript:`、`data:`、文件 URL、浏览器内部页。
- 标签：代理标签可新建/切换/关闭；用户标签关闭必须确认。
- 弹窗：`alert/confirm/prompt` 由 CDP 处理；确认内容前不自动接受。
- 下载：P1；必须确认，不自动打开文件。

### 8.2 等待与验证

- 导航后等待 `tabs.onUpdated` 完成 + DOM 稳定（MutationObserver 静默 ≥300ms）。
- 点击后如触发导航，等待新文档；未触发导航则等待 DOM 稳定。
- 动作结果返回：URL、标题、是否导航、可见错误提示、是否需要重新观察。
- 意外下载、意外跨域导航、页面跳转到登录/验证码：立即暂停。

### 8.3 debugger 生命周期

- 每个任务一个 CDP 会话；按标签 attach，任务结束/停止/接管时 detach。
- 超时：单条命令 8–12 秒；页面加载 20 秒；任务 5 分钟。
- 不允许自动重连；`isCancelled` 后所有命令抛 `AbortError`。
- 与其他扩展/DevTools 争用 debugger 时，明确提示用户关闭冲突来源。

## 9. 界面与权限管理

### 9.1 入口

- 侧栏新增“浏览器控制”开关/盾牌入口；默认关闭。
- 首次开启显示风险说明：可读取页面、点击、输入、切换标签；随时可停止/接管。
- 任务输入与普通对话分开，避免用户把“总结页面”误当成“自动操作”。

### 9.2 运行时界面

- 任务状态条：运行中 / 等待确认 / 已暂停 / 已接管 / 已完成 / 已失败 / 已取消。
- 时间线：每一步显示动作、目标文本、风险、结果；可展开截图。
- 目标高亮：执行前在页面高亮目标元素；确认弹窗包含截图或元素文本。
- 停止按钮始终可见；接管按钮始终可见。
- 审批弹窗：origin、动作、目标、风险、允许一次/取消；默认焦点在取消。
- 接管横幅：说明“Agent 已暂停，你可以接管页面”，提供继续/结束。
- 恢复横幅：扩展重启/页面变化后提示核对当前页面，再继续。

### 9.3 设置页

- 全局浏览器控制开关。
- 严格模式：所有动作都确认（默认关闭）。
- 已授权站点列表：origin、授权范围、最近使用、撤销。
- 审计日志：最近任务、导出、清除。
- 安全说明：不自动支付、不自动输入密码、不绕过验证码、不后台潜伏。

## 10. 数据模型与存储

- `agentSettings`：`{ enabled, strictMode, captureEvidence, maxSteps, maxMinutes }`
- `originGrants`：`{ "https://example.com": { scope: "task"|"always", grantedAt, lastUsedAt } }`
- `agentTask`：`{ version, id, goal, status, origin, tabId, ownedTabs, step, maxSteps, startedAt, deadline, lastSnapshot, pendingAction, result, error }`
- `agentStep`：`{ step, actionId, action, argsHash, target, risk, approval, result, observationSummary, screenshotId, startedAt, endedAt }`
- `agentLog`：本地审计日志；默认只记录动作元数据，不记录输入原文和密码。
- 存储位置：任务检查点用 `chrome.storage.session`；设置/授权用 `chrome.storage.local`；截图/大日志用 IndexedDB；导出由用户主动触发。
- 容量：截图数量/大小上限，任务日志环形保留；提供一键清除。
- 隐私：页面内容、截图、日志不上传第三方；模型请求只发送当前决策所需的最小观察摘要。

## 12. 分期、验收与指标

### 12.0 当前实现状态（2026-10-29，0.17）

已落地 P0 单页核心链路：

- 全局浏览器控制开关、严格模式、按 origin 授权与设置页站点撤销；
- 单活动标签页的结构化观察、点击、输入、滚动、导航、等待；
- 执行前 `elementRef` 连通性/可见性/位移/遮挡校验，失效即要求重新观察；
- 密码/CVV/PIN、支付/下单、上传、验证码、跨站/新标签页的风险分级与硬阻断；
- 提交/发送/删除/发布等逐次确认，密码/支付不可确认绕过；
- 人工接管、停止、任务检查点与重启后的 `PAUSED_RECOVERY`（不自动重放）；
- tools/tool_calls 优先 + 严格 JSON 动作 fallback；
- 本地审计（任务、步骤、阻断/确认结果，不含截图持久化）。
- Agent 任务作为普通对话回合持久化：用户目标、执行时间线、人工接管、暂停恢复和最终摘要均可在历史、追问与导出中看到；
- 执行期间页面显示浅色遮罩，用户点击页面即暂停自动操作并接管，恢复时重新观察页面；
- 完成摘要基于执行记录生成，模型不可用时使用确定性摘要兜底。
- 0.17 增加重复动作签名与循环熔断、任务看门狗超时、异常退出自动失败收尾；任务卡片运行中固定高度并自动跟随最新步骤，结束或失败后自动折叠；暂停/接管后可恢复输入和页面总结。

尚未落地（继续按 P1/P2）：

- 用户标签 claim、多标签/标签组、后台持久任务；
- 文件上传/下载、剪贴板、历史/书签；
- 坐标 CUA 兜底与 CDP trusted input（P0 先用隔离世界 DOM 动作 + 几何校验）；
- 截图证据持久化、任务报告导出、MCP/WebMCP、受控 JS Kernel。

实现取舍：P0 不向模型暴露原始 CDP 或任意 JS；DOM 动作在部分要求 `isTrusted` 的站点可能失效，P1 再增加 CDP Input 通道，不改动权限与安全门。

### 12.1 P0 验收

在本地 fixture 站点完成并通过：

- 全局关闭时任何动作被拒绝，阅读不受影响。
- 未授权 origin 触发授权弹窗；拒绝后不产生任何页面副作用。
- 搜索 → 打开第一条结果 → 读取结果，全流程可完成。
- 移动到/遮挡/移除的目标：返回对应错误并重新观察，不盲点坐标。
- 密码框输入被硬阻断；支付按钮被硬阻断；删除/提交需要逐次确认，取消后无副作用。
- 跨域导航触发 origin 授权；拒绝后停留原页。
- 停止后 500ms 内 detach，且无自动重连。
- 接管后恢复必须重新观察，旧快照不可用。
- 扩展重启后进入 `PAUSED_RECOVERY`，不自动重放。
- 登录/验证码/反自动化页面暂停并请求接管。
- 每一步有审计记录；高危动作有截图证据；导出不含密码/API Key。
- 至少一个支持 tools 的模型和一个不支持 tools 的模型都能跑通（后者走 JSON fallback）。

### 12.2 P1 验收

- 用户标签 claim、标签保留/交付物、多标签切换。
- 文件上传由用户选择文件；下载需确认；剪贴板需单独授权。
- 重试/卡死检测/轨迹压缩；长任务上下文不溢出。
- 站点权限列表可撤销，撤销立即生效。

### 12.3 指标

- 任务成功率、平均步数、人工确认次数、接管次数。
- 危险动作拦截率（应为 100%）。
- 停止延迟、恢复成功率。
- 每步观察/动作耗时、上下文 token 使用量。
- 真实网页回归失败率与回归原因分类。

## 13. 开放决策

以下决策需要在开工前确认：

1. **任务生命周期**：P0 是否明确“侧栏关闭即暂停并释放控制”？建议是；持久后台任务放 P2。
2. **默认站点授权**：默认“仅本次任务”，用户可主动选“始终允许”；不建议默认始终。
3. **严格模式**：默认关闭，仅对高危动作确认；企业/演示可开“每步确认”。
4. **坐标兜底**：P0 不做；P1 只用于无 DOM 的 canvas/图表，并必须截图确认。
5. **文件上传/下载/剪贴板**：放 P1；P0 不做，避免扩大权限面和风险。
6. **动作空间**：P0 采用类型化工具；P2 再评估受控 JS Kernel。不要把任意 JS 作为 P0 捷径。
7. **模型兼容**：先选一个支持 tool calling 的模型做基准，同时用 JSON fallback 覆盖 DeepSeek/Ollama 等。
8. **历史/书签/多窗口/标签组**：P1/P2 再评估；P0 不申请新增权限。
9. **支付/账号注销**：建议永久硬阻断，不提供“始终允许”。
10. **审计截图**：默认只保留关键动作，避免存储膨胀和隐私风险。

## 14. 完成定义

P0 完成不等于“能点按钮”，而是同时满足：

- 能在受控范围内完成真实任务；
- 任何危险动作都有确定性拦截或用户确认；
- 用户随时能停止、接管、撤销站点授权；
- 失败能解释、能恢复、不会重复执行不可逆动作；
- 每一步有本地证据和审计；
- 现有阅读、PDF、对话和导出能力不回归。

满足以上条件，二期才达到“可控制页面 + GPT 级安全权限”的产品基线。
