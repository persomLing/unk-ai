# 0.17.7：P1 问答内核与扩展隔离

发布日期：2026-11-02。

## 更新内容

- 普通发送、队列、停止、重试迁入应用服务；按会话和回合绑定消息，唯一提交终态，拒绝旧执行的迟到事件。
- 主回答、Agent 决策、视觉判断、历史压缩和建议问题统一经过模型网关，固定配置并分开管理超时与取消。
- 可选能力工厂和上下文失败隔离；压缩不可用时仍能完成主回答，必要资料不可用时明确报错。
- 修复重复生成清空已输出正文，以及双击发送第二下误触原位置停止按钮的问题。
- 完善初始化超时、监听清理、释放后命令拦截和跨回合界面绘制。

完整架构和剩余范围见 [P1 交付总结](2026-11-02-p1-runtime.md)。本版保留既有受控浏览器 Agent；通用工具执行器、MCP、Skill 和记忆仍在后续阶段。

## 安装

交付包为项目根目录的 `unk-ai-v0.17.7.zip`，ZIP 根目录直接包含 `manifest.json`。

解压到独立目录后，在 `chrome://extensions` 打开开发者模式，选择“加载已解压的扩展程序”并选择该目录。已经加载本项目 `dist` 的用户可点击扩展的重新加载按钮；原有旧版压缩包保留。
